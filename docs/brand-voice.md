# Kepos Communis · 品牌语言

## 主张

**让效率回到人的目的。**

工作可以交由工具推进。目的与判断，由你决定。

## 产品介绍

Kepos Communis 是人与 Agent 共同工作的终端空间。它组织任务分派、并行协作与证据汇集，让你看清工作的进展，并在需要时介入、暂停或重新确定方向。

## 理念

工具的能力不断增长，工作为何值得做，仍然需要人的判断。

Kepos 让不同的 Agent 带回各自的发现，也让这些发现保留可以检查的来处。你可以比较分歧、检验结论，重新安排下一步。一次运行的完成，并不意味着问题已经得到回答。

Kepos 意为花园。共同工作的空间，需要持续照料：成果有来处，分歧能被看见，方向可以重新讨论。

## 语气

以“工具理性反思型”为品牌语言方向，借鉴对目的、自主判断和技术关系的关切。所有文案为原创，不作为法兰克福学派任何作者的引文，也不声称产品实现了某种哲学理论。

- 有立场，使用具体的产品动作表达：检查、比较、暂停、修改、继续。
- 清楚区分产品事实和品牌愿景。人类门禁、任务记录等能力按实际实现描述。
- 讨论效率时，同时交代它服务的工作和人。
- 允许提问、分歧和重新考虑，不将多 Agent 的一致意见包装成真理。
- 对话礼貌、平实。功能提示首先告诉使用者发生了什么、能做什么。
- 花园作为空间隐喻适度使用，避免把每个功能都写成播种、发芽或收获。

## 功能文案

| 场景 | 文案 |
| --- | --- |
| Council | 让不同的发现进入同一场讨论。 |
| Mission | 看清进展，也保留改变方向的余地。 |
| Evidence | 结论应当带着可以检查的来处。 |
| 需要人类处理 | 此步骤需要你的决定。查看详情后，选择继续或暂停。 |
| 任务完成 | 本次任务已结束。查看结果与证据，再决定下一步。 |
| 任务失败 | 此步骤未完成。查看错误与已保留的结果后，可以重试或调整任务。 |

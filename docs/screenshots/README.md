# 截图清单（上线物料）

README 引用的界面截图统一放在本目录。拍摄要求：真彩终端（Windows Terminal）、
默认主题 `kepos-default`、窗口 ≥ 140×36、无个人凭据入镜。

| 文件名 | 内容 | 用于 |
|---|---|---|
| `hero-demo.gif` | 开机 splash → 议案输入 → F10 议会单环 → 点击席位开书案 → 四小组聚环 → 预算审批弹窗（15–25s，<8MB） | README 顶部演示 |
| `council.png` | 议会视图：红色 ★ 总理居中、48 席单环、活跃席位呼吸、选中席位高亮 | 特性 · 议会环图 |
| `desk.png` | 议案三栏：代表席 / 对话（人类消息左缘条）/ 项目列表 | 特性 · 议案 |
| `desk-view.png` | 代表书案：等待区、产出、用量（Token ↑↓/缓存命中） | 特性 · 书案 |
| `approval.png` | 预算审批前置弹窗（一键批准/自定义/拒绝） | 特性 · 审批 |

录制建议：`copilot`/`asciinema` 录制后转 GIF，或 Windows Terminal + ScreenToGif。
拍好放本目录后，README 中的 `<!-- 截图位 -->` 注释处按文件名替换即可。
